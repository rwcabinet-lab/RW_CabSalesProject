# 系統櫃工廠業務報價與案件時程追蹤系統

本專案為系統櫃／櫥櫃工廠量身打造的整合業務管理系統，將「客戶資料主檔、案場時程監控、里程碑與待辦派工、外部報價登記、以及多維度營運看板」整合於現代化 Web 平台中。

---

## 📌 系統核心亮點與最新架構

### 1. 全新 7 大標準階段 + 額外階段時程引擎
系統完整涵蓋由前端接洽至售後結案之 28 個細部子進度：
1. **第一階段：案件開發**（客源開發、案件分配）
2. **第二階段：現況及需求確認**（需求訪談、設計建議、圖面索取、丈量、場勘）
3. **第三階段：設計提案/報價/簽約**（設計圖製作、設計圖審核、報價單製作、報價單審核、提案簡報製作、提案簡報、合約製作、合約審核、送約/簽約）
4. **第四階段：生產前確認/拆單**（復丈、二次場勘、施工圖製作、施工圖審核、拆單並提交生產）
5. **第五階段：生產及派送**（生產、出貨、派工）
6. **第六階段：安裝及驗收**（安裝、監工及現場處置、工程驗收、提交成果驗收、加減帳）*(追補料視為新案件獨立開單)*
7. **第七階段：結案/售後**（批價、請款、追蹤二次回購）
- **額外階段**：收尾中、已流標。

### 2. 智慧子進度排序與自動推進
- **子進度自訂排序**：可依照各案場實際運作情形，上下微調子進度順序（持久化存入資料庫）。
- **連動推進**：按下完成後，系統依排序自動將下一項標記為「進行中」，並同步更新案場狀態總覽。
- **審核流動機制**：涉及「繪圖 / 報價 / 提案 / 合約 / 施工圖」之審核節點，負責人員具備「提交審核」按鈕，提交後自動發送待辦予主責業務或主管，由其確認審核完成後方推進。
- **全項目 [+] 歷次紀錄折疊面板**：任何進度（場勘、丈量、繪圖、報價等）皆可多次追加記錄（如第二次覆量、追加報價單），記錄可展開/收合。
- **流標鎖定**：進入「已流標」後，該案場所有里程碑鎖定為唯讀狀態，防止誤改。

### 3. 業務工作台與主管監控室案件清單統一
- **全域欄位設定**：管理員於後台可自由增減、勾選啟用或上下調整各欄位排列順序（狀態燈號、案場/地址、客戶折數、負責業務/業助、目前階段、當前進度、預算/金額、戶數、預計完工日、操作）。
- **業務/主管共用規格**：業務工作台僅呈現該業務負責或被指派案件；主管監控看板呈現全公司案件並額外提供指派任務操作。
- **預設過濾保護**：案件清單預設呈現「進行中案件」，自動排除已流標與已立帳（但仍可隨時透過下拉選單切換檢視）。

### 4. 系統管理與個人風格
- **帳號密碼維護**：支援帳號編輯與密碼變更介面（目前測試驗證維持 `0000`）。
- **預設天數自訂**：管理者可設定 28 個子進度預設標準作業天數，建立新案件時自動套用。
- **多樣化介面風格**：提供經典藍、極簡深色、森林綠、暖陽橘、質樸灰等色彩主題，以及寬鬆與緊湊兩種畫面密度切換。
- **效能優化**：API 平行並發請求、預先抓取（Prefetching）機制，大幅縮短頁面切換與點擊響應延遲。

## 🛠 技術棧

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript 5.6
- **Database / ORM**: Supabase PostgreSQL + Prisma ORM 5.22
- **UI / Styling**: React 18, Tailwind CSS, lucide-react
- **Data Visualization**: Recharts (圖表分析)
- **Architecture**:
  - `src/app/`：App Router 路由、API 端點及前端介面
  - `src/lib/data-service.ts`：資料庫查詢與業務邏輯層
  - `src/lib/schedule-engine.ts`：時程計算與燈號引擎
  - `src/lib/mock-data.ts`：階段定義、常數對照表與全域設定
