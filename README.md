# 業務時程追蹤平台（正道工業系統櫃事業部）

整合客戶資料管理、案場分期與 7 大標準工程階段（28 項里程碑）、待辦任務、報價紀錄、視覺時程甘特圖／行事曆、營運戰情統計及全體公告管理的 Web 系統。

## 主要功能

### 1. 案件狀態總覽與清單（案場筆記 & 主管總控）

- **全域一致欄位**：案場筆記與主管總控共用案件欄位設定（`狀態`、`案場 工地`、`客戶 折數`、`業務 業助`、`階段 進度`、`報價 戶數`、`進場日`、`立帳日`、`操作`），複合欄位採上下主次兩行顯示，由管理員於「管理設定」統一維護順序與顯示狀態。
- **跨頁記憶篩選與排序**：支援狀態燈號、工程階段與關鍵字搜尋，以及「進場日」、「立帳日」、「狀態」排序（主管總控另支援點擊「業務」欄位依繁體中文筆畫排序，將相同業務的案場集中於同區塊），設定自動持久化並提供【回復預設】一鍵還原。
- **跨裝置圖釘置頂（📌）**：以個人帳號隔離並於本機與雲端同步置頂案件。
- **多期分期樹狀管理**：母案列顯示「共 N 期」彙總報價、成本與最緊迫燈號，展開各分期子列具備獨立 28 項里程碑與【項目推進】操作。
- **預設排除**：預設僅列出進行中案件，排除已流標與已立帳結案案場。

### 2. 案場筆記 (`/dashboard/workbench`)

- **個人化待辦整合**：頂部待辦區整合指派給個人的進行中里程碑與主管交辦任務；逾期待辦以紅底與「已逾期」醒目標籤標記。
- **快速項目推進、單項略過與一鍵跳轉**：點擊【項目推進】可直接推進進度；主管與主責業務另可勾選「此項略過」，或下拉選擇後續進度執行「一鍵跳轉」（上限至 `6-5 提交成果驗收`，預設勾選「以上略過」）。
- **行內展開編輯**：點擊編輯圖示，表單直接於該列下方行內展開，金額輸入統一以「整數元」為基準（先「成本金額」後「報價金額」）。

### 3. 主管總控 (`/dashboard/manager`)

- **核心 KPI 精準統計**：即時統計進行中總案場數、已簽約／生產預估總額（`3-6 送約/簽約` 已完成之案件）、成交率與逾期案件數。
- **人員案場負載與 7 大階段瓶頸分析**：負載圖排除流標、已結案與多期母案重複計數，精準反映實際工作量與階段卡關分佈。
- **業務欄位筆畫分區排序與交辦任務**：點擊「業務」表頭可依繁體中文筆畫排序並將同業務案件集中；主管可直接為特定案場指派獨立任務。
- **客戶資料統計分析**（`/dashboard/manager/customers`）：彙整各客戶合作案場數、進行中數、成交總額、報價總額、預設折數及類型分佈。

### 4. 案場細節與里程碑 (`/projects/[id]/milestones`)

- **案場資料直接編輯**：頂部提供【編輯案場資料】，可維護案名、地址、戶數、成本、報價、進場日、立帳日（`7-2 立帳` 完成後鎖定唯讀）及現況說明。
- **進場日與立帳日獨立排程**：
  - 未手動填入進場日前，`6-1 進場安裝` 至 `6-5 提交成果驗收` 維持空白；填入進場日後自動推算 `6-2 ~ 6-5`。
  - 前段（`1-1 ~ 5-2`）改期同步平移、提前完成、退回還原與「需追蹤」暫停皆於 `5-2 出貨` 止步，不牽動進場日與立帳日；第七階段（`7-1 ~ 7-3`）採全手動排程。
- **一鍵跳轉與項目略過（限主管與主責業務）**：
  - 細節頁未開始項目（至 `6-5`）右側提供精簡【跳轉／至此】按鈕，已完成的項目維持全寬；跳轉預設勾選「以上略過」，以今日重新推算後續前段預定日。
  - 單項【進度完成】視窗（含尚未送審之需審核項目）可勾選「此項略過」，實際完成日留空並標示為「已略過」。
- **4 項審核關卡與回退機制**：`3-1 設計圖`、`3-2 報價單`、`3-5 合約擬定`、`4-4 施工圖` 支援送審（紀錄「實際提交審核時間」）、撤回／退件（同步清除送審時間）與審核完成；最後一筆已完成／已略過項目可由主管或主責業務點擊【回退至此】退回重辦。
- **歷次執行紀錄 `[+]`**：支援丈量、場勘、報價（`3-2`、`7-1`）多次紀錄填報。
- **7 大標準階段（共 28 個子進度）**：
  1. **案件開發**：`1-1` 客源開發、`1-2` 案件分配
  2. **現況及需求確認**：`2-1` 需求訪談、`2-2` 設計建議、`2-3` 圖面索取、`2-4` 丈量、`2-5` 場勘
  3. **提案／報價／簽約**：`3-1` 設計圖、`3-2` 報價單、`3-3` 提案簡報製作、`3-4` 提案簡報、`3-5` 合約擬定、`3-6` 送約／簽約
  4. **生產前確認／拆單**：`4-1` 復丈、`4-2` 二次場勘、`4-3` 派工、`4-4` 施工圖、`4-5` 對圖
  5. **生產及派送**：`5-1` 生產、`5-2` 出貨
  6. **安裝及驗收**：`6-1` 進場安裝、`6-2` 追補料、`6-3` 收尾、`6-4` 內部驗收、`6-5` 提交成果驗收
  7. **立帳／結案**：`7-1` 加減帳、`7-2` 立帳、`7-3` 結案
- **額外階段**：`X-2` 流標（鎖定案件里程碑為唯讀，主管可取消流標恢復進行）。

### 5. 視覺時程、帳號管理與系統治理 (`/views`, `/settings`, `/admin`)

- **視覺時程**（`/views`）：甘特圖（含分期跨度、預定／實際落差連線與縮放拖曳）與外勤行事曆（僅顯示進行中里程碑與獨立待辦）。
- **個人設定與帳號安全**（`/settings`）：採用 scrypt 隨機鹽值密碼雜湊與強密碼規範（至少 8 碼且含英數字）、未變更初始密碼登入提醒、個人金額單位切換（元／萬）、5 款主題配色與排版密度切換。
- **管理設定與改版資訊**（`/admin` & 導覽列）：全域欄位／預設工期／客戶起始進度設定、角色頁面授權矩陣、全體公告欄（登入自動推播）與系統改版資訊彈窗。

## 技術架構

- **Framework**：Next.js 14 App Router
- **Language**：TypeScript
- **Database / ORM**：PostgreSQL (Supabase)、Prisma ORM
- **UI & State**：React、Tailwind CSS、Zustand、TanStack React Query、lucide-react
- **資料視覺化**：Recharts
- `src/app/`：頁面與 API 路由
- `src/lib/services/`：領域服務層（案場、里程碑、客戶、待辦、設定）
- `src/lib/schedule-engine.ts`：單一真理來源時程引擎（四色燈號、推進、跳轉與評估）
- `src/lib/constants.ts`：7 大階段與 28 項里程碑定義、預設工期與欄位常數
- `prisma/schema.prisma`：資料庫模型

## 常用指令

```bash
# 開發伺服器
npm run dev

# 同步 Prisma schema 至資料庫
npx prisma db push

# 產生 Prisma Client
npx prisma generate

# TypeScript 型別檢查
npx tsc --noEmit

# 執行單元與整合測試
npx vitest run

# 正式環境建置
npm run build
```
