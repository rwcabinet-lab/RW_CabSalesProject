# 系統櫃工廠業務與案件管理系統

整合客戶與案場資料、案件階段與里程碑、待辦任務、報價記錄及營運看板的 Web 系統。

## 主要功能

### 案件狀態總覽

- 業務工作台與主管看板共用案件欄位設定。
- 報價與戶數合併顯示於「報價／戶數」欄。
- 案件階段與目前進度合併顯示於「階段 / 進度」欄，進度以次要資訊呈現。
- 管理員可設定總覽欄位的顯示與順序；舊版分開儲存的欄位會在讀取時合併。

### 案件細節

- 顯示案場地址、現況、客戶資料、折數、業務與助理、案件階段、時程、戶數、報價、預算及成本等案件欄位。
- 里程碑分為七個標準階段，共 27 個子進度：
  1. **案件開發**：客源開發、案件分配
  2. **現況及需求確認**：需求訪談、設計建議、圖面索取、丈量、場勘
  3. **設計提案／報價／簽約**：設計圖、報價單、提案簡報、合約、送約／簽約
  4. **生產前確認／拆單**：復丈、二次場勘、施工圖、拆單並提交生產
  5. **生產及派送**：生產、出貨、派工
  6. **安裝及驗收**：安裝、監工及現場處置、工程驗收、提交成果驗收、加減帳
  7. **結案／售後**：批價、請款、追蹤二次回購
- 主管可拖曳調整子進度順序；完成里程碑後，系統會依排序推進下一項。
- 需要審核的項目由負責人提交，審核人員完成。
- 各里程碑可記錄歷次執行日期與備註；僅報價相關進度可填報價金額。
- 里程碑區域下方顯示已完成待辦備查，頁面最下方顯示未完成待辦。
- 進入「已流標」的案件，其里程碑唯讀。

### 階段以外的案件狀態

- **收尾中**：透過額外的收尾進度處理。
- **已流標**：鎖定案件里程碑，避免繼續編輯或推進。

### 管理與介面

- 管理員可維護使用者、權限、總覽欄位、里程碑預設天數及介面主題。
- 提供經典藍、深色、森林綠、暖陽橘、質樸灰等主題，以及寬鬆與緊湊畫面密度。

## 技術架構

- **Framework**：Next.js 14 App Router
- **Language**：TypeScript
- **Database / ORM**：PostgreSQL、Prisma ORM
- **UI**：React、Tailwind CSS、lucide-react
- **資料視覺化**：Recharts
- `src/app/`：頁面與 API 路由
- `src/lib/data-service.ts`：資料庫存取與業務邏輯
- `src/lib/schedule-engine.ts`：里程碑排序、推進與時程評估
- `src/lib/mock-data.ts`：階段定義、預設欄位與設定常數
- `prisma/schema.prisma`：資料庫模型

## 常用指令

```bash
# 安裝相依套件
npm install

# 開發伺服器
npm run dev

# 同步 Prisma schema 至資料庫
npx prisma db push

# 產生 Prisma Client
npx prisma generate

# TypeScript 型別檢查
npx tsc --noEmit

# 程式碼檢查
npm run lint

# 建置與執行正式版本
npm run build
npm start
```
