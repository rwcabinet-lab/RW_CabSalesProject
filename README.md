# 系統櫃工廠業務與案件管理系統

整合客戶與案場資料、7 大標準案件階段與里程碑、待辦任務、報價記錄、客戶資料統計及營運監控看板的 Web 系統。

## 主要功能

### 1. 案件狀態總覽與清單（業務工作台 & 主管監控室）

- **全域一致欄位**：業務工作台與主管看板共用案件欄位設定，由管理者統一維護顯示狀態與排序。
- **欄位合併呈現**：報價與戶數合併顯示於「報價／戶數」欄；案件階段與目前進度合併顯示於「階段 / 進度」欄。
- **雙向排序功能**：支援「預定完工日」與「案件狀態燈號（逾期/已到期/即將到期/正常/已流標）」即時排序。
- **篩選結果統計**：即時顯示目前篩選條件下的總案場數及報價總金額。
- **預設排除**：預設僅列出進行中案件，排除已流標與已立帳案場。

### 2. 業務工作台 (Sales Workbench)

- **待辦事項整合**：指派給個人的正規里程碑與任務自動整合於待辦清單中；逾期待辦事項以紅底、紅字與「已逾期」醒目標籤標記。
- **行內展開編輯**：點擊案件「編輯」按鈕，編輯表單直接於該列下方行內展開（Inline Collapsible），提升操作流暢度。
- **個人化待辦範圍**：管理者與各身分待辦事項僅顯示指派給自己的任務，不混雜其他帳號之事項。

### 3. 主管監控室 (Manager Dashboard)

- **核心 KPI 精準統計**：
  - 「已簽約/生產預估總額」與「成交率」嚴格統計【送約／簽約】（`3-5`）項目已完成之案件。
  - 「逾期案件」整合即時時程引擎評估，精準掌握真實逾期專案數。
- **7 大主要階段瓶頸分析**：專注分析 7 大標準階段之案場停留數與卡關延誤狀況。
- **客戶資料統計分析（新增）**：
  - 提供獨立客戶統計頁面（`/dashboard/manager/customers`）。
  - 彙整各客戶合作案場數、進行中數、成交金額、預設折數及類型分佈。
  - 支援關鍵字搜尋（名稱/統編/電話）、類型篩選、業務篩選與多維度排序。

### 4. 案件細節與里程碑 (Milestones)

- **案場資料直接編輯**：案件細節頁頂部提供「編輯案場資料」功能，可隨時維護案場名稱、地址、戶數、成本、報價、預計完工日及現況說明。
- **全員拖曳調整順序**：所有帳號身分皆可拖曳調整子進度圖卡順序；完成前一項後自動啟動下一順位進度。
- **歷次執行紀錄 / 追加填報**：支援多次場勘、丈量、繪圖、報價填報，新增「負責人員」欄位並記錄執行歷程。
- **審核機制連動**：需審核項目（設計圖、報價單、提案簡報、合約、施工圖）由負責人提交審核，審核人員完成後自動解除等待審核標籤並推進下一進度。
- **7 大標準階段（共 27 個子進度）**：
  1. **案件開發**：客源開發、案件分配
  2. **現況及需求確認**：需求訪談、設計建議、圖面索取、丈量、場勘
  3. **設計提案／報價／簽約**：設計圖、報價單、提案簡報、合約、送約／簽約
  4. **生產前確認／拆單**：復丈、二次場勘、施工圖、拆單並提交生產
  5. **生產及派送**：生產、出貨、派工
  6. **安裝及驗收**：安裝、監工及現場處置、工程驗收、提交成果驗收、加減帳
  7. **結案／售後**：批價、請款、追蹤二次回購
- **額外階段**：
  - **收尾中**：透過額外的收尾進度專屬追蹤。
  - **已流標**：鎖定案件里程碑為唯讀狀態，避免變更。

### 5. 個人設定與系統風格（新增）

- 獨立個人設定頁面（`/settings`），導覽列右上角提供快速入口。
- **密碼管理**：提供密碼變更介面（開發相容模式預設為 `0000`）。
- **多款介面風格**：提供經典商務藍、翡翠森林綠、溫潤暖木褐、專業極簡灰、夜間深色模式等多種配色，點擊即時套用並儲存。
- **表格顯示密度**：支援舒適標準與緊湊高容量兩種顯示密度切換。

## 技術架構

- **Framework**：Next.js 14 App Router
- **Language**：TypeScript
- **Database / ORM**：PostgreSQL (Supabase)、Prisma ORM
- **UI**：React、Tailwind CSS、lucide-react
- **資料視覺化**：Recharts
- `src/app/`：頁面與 API 路由
- `src/lib/data-service.ts`：資料庫存取與業務邏輯
- `src/lib/schedule-engine.ts`：里程碑排序、推進與時程評估
- `src/lib/mock-data.ts`：階段定義、預設欄位與設定常數
- `prisma/schema.prisma`：資料庫模型

## 常用指令

```bash
# 開發伺服器
npm run dev

# 同步 Prisma schema 至資料庫
npx prisma db push

# 產生 Prisma Client
npx prisma generate

# TypeScript 型別檢查
npx tsc --noEmit
```
